# Weekly recap meme templates

The weekly recap feature (`python app.py post-weekly`) rotates through the image
files in this folder, one per week, least-recently-used first. Drop your own
meme templates here (`.png` / `.jpg`).

- Files with `example` in the name are ignored.
- Set the folder location with `WEEKLY_TEMPLATE_DIR` (defaults to `template`).
- ~52 images gives a full year with no repeats.

The original template images are omitted from this repository because they are
large source files; supply your own.
